# 仕分け宣言の例（4本ぶん）

定期 ingest の Step 1 で AI が出す宣言の見本です（AGENTS.md §3-1）。**質問せず宣言し、訂正がなければ進みます**（黙認方式）。承認（「wiki に保存してよいですか？」→ OK）を経てから wiki が書かれます。

**いちばん見てほしいのは、日記の2欄が別々の行き先を持つこと**です。「あったこと」欄だけが本人のページ（sentaku / trial / trigger / 手順書 / koe）の素材になり、「おもったこと」欄は原則 raw に留まります（purpose.md A-10）。

---

## ① 日記 2026-07（そら・P_900）

```
7月の日記を読みました。仕分けを宣言します。

【あったこと欄から】
　7/3 言葉だけの二択で固まって泣いた → ためしたこと（trial・failure）
　7/4 実物の二択でゼリーを指さした → ためしたこと（trial・success）＋せんたく（尊重された）
　7/8 絵カード二択×今週3回 → せんたく（尊重された）。7/4 とあわせ、こえ（意思表出プロファイル）の初版を起草する材料が揃いました
　7/9 ドライヤーで耳をふさいで大泣き → きっかけ（distress・聴覚）
　7/16 浴室の外で使ったら泣かなかった → 手順書（bath）「ドライヤーは浴室の外で」
　7/11 水遊びの日はご機嫌 → きっかけ（joy）
　7/1 靴を自分で選んだ・7/15 服の二択 → せんたくには起こさず、こえの「伝わりやすい示し方」の根拠に含めます

【おもったこと欄から】
　7/15「三択はまだ難しいのかも」→ 親の仮説として、こえに載せるか確認待ち（review）に1件起票します
　7/13（妹さんへの思い）→ raw に留めます。wiki には上げません
　その他の思い → すべて raw に留めます

違っていたら教えてください。
```

> **判断規則の適用例**:
> - 「固まって泣いた」（7/3）は失敗に見えるが、**失敗の記録こそ価値が高い**（purpose.md §3-2）。この trial が「言葉だけの質問は表出を妨げる」という こえ の1行を支える証拠になる
> - 7/15 の「三択はまだかも」は**親の解釈**なので、事実欄由来のページに直接書かない。こえ に載せるなら「親の仮説」と明記する——その判断を親に委ねるのが review 起票（A-10 のフロー）
> - 7/13 は本人の記録ではなく親ときょうだいの物語。**思いとして歓迎され、raw に留まる**（§3-9・§3-10）

## ② 連絡帳の写真・園から（そら・P_900）

```
園からの連絡帳として受け取りました。
　原本 → raw/20_園・学校・療育から/（写真のまま保存）
　読み取り → 2026-07_連絡帳.pdf.読み取り.md を原本の隣に作ります（誤読を含む旨と原本リンクを冒頭に付けます）
　7/8 5分前の「おしまい」絵カードで切り替え → 手順書（切り替えの予告）候補。日記の絵カード二択と同じ「視覚で示す」系
　7/12 お友だちのおもちゃを待てた → ためしたこと（TD・他者の決定権を学ぶ過程）。園の対応をそのまま記録します
　7/16 工事の音の日は寝つきにくい → きっかけ（distress・聴覚）の関連情報として 7/9 のドライヤーのページに追記
違っていたら教えてください。
```

> **判断規則の適用例**: 7/12 は「順番を待てた」という幼児期の小さな事実だが、**他者の決定権を学ぶ過程の最初の記録**（purpose.md §3-0 第二の柱）。本人を注意した記録ではなく、機能した関わり方（「終わったら貸してもらおうね」＋一緒に待つ）の記録として書く。
>
> **原本と読み取りの分離（A-11）**: 抽出のもとにするのは読み取りテキストだが、生成する wiki ページの `sources` に書くのは**原本**（`2026-07_連絡帳.pdf`）である。読み取りを典拠にしない。判読できなかった箇所は `〔判読できず〕` のまま残し、想像で埋めない。

## ③ 日記 2026-07（かえで・P_901）

```
7月の日記を読みました。仕分けを宣言します。

【あったこと欄から】
　7/10 見学先を写真から自分で選んだ → せんたく（尊重された・仕事）
　7/18 「一人で帰りたい」→ 通らなかった → せんたく（通らなかった）。通らなかった理由（乗換2回・夕方の混雑）を override_reason に必ず記録します
　7/22 バス1区間の練習 → ためしたこと（trial・partial）。7/18 のせんたくの「学び」の実行です
　7/5 パン工房のページを何度も見ていた → 7/10 のせんたくの「場面」に含めます
　7/27 猫の動画で笑う → 小さな記録として こえ・きっかけの材料に留めます（単独ページにはしません）

【おもったこと欄から】
　7/18「悔しい。切り替えたい」→ raw に留めます。ただし「段階練習に切り替える」という方針は 7/22 の事実（実際に練習した）として記録されます
違っていたら教えてください。
```

> **判断規則の適用例**: 「通らなかった」は**隠さずに記録する**。本人の意思と異なる判断をしたときこそ、理由を残す（意思決定支援ガイドライン／schema.md §3-1）。この記録があるから、後の支援者は「バスの一人利用は検討済み・段階練習中」と分かり、本人の希望を「なかったこと」にしない。

## ④ 進路面談メモ（かえで・P_901）

```
面談のメモとして受け取りました。
　原本 → raw/70_会議・面談/
　「写真や実物があると選びやすい・言葉だけだと表情が止まる」（先生の観察）→ こえ の材料（provided_by: 園・学校）
　見学先決定の経緯 → せんたく 7/10 の「その後」に追記
　バス通学の段階案（休日練習→停留所見守り→2学期再相談）→ 手順書候補。2学期の相談結果が出たら起草を提案します
　着替えは決まった場所で（学校と家庭で揃える）→ とりあつかい注意（sensitive）の「からだとプライベートゾーン」ページを起草し、確認待ちに1件起票します
違っていたら教えてください。
```

> **判断規則の適用例**: 着替えの話題は思春期の身体の尊厳に関わるため、internal の手順書ではなく **sensitive**（目的の明示・双柱の書き方・share_scope: origin-only）で起草する。学校の言葉をそのまま貼らず、「何のために記録するか」から書き始める。
