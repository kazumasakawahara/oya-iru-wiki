# ドライヤーは浴室の外で（見本）

> 日記の1行（7/16「浴室の外で使ったら泣かなかった」）が手順書になるまでの見本です。手順書は「現時点で機能している手順」であり、成長とともに更新されます。

## 目的

入浴後の髪の乾燥を、そらが泣かずに終えられるようにする。お風呂そのものが嫌いになるのを防ぐ。

## 適用条件

入浴後、髪を乾かすとき。実施者は家族（園・祖父母宅など他の場所でも同じ形を推奨）。

## 手順

1. そらが浴室を出て、リビング側へ移動してから乾かし始める
2. ドライヤーは**廊下（浴室から離れた場所）**で使う。風が顔に直接当たらない角度にする
3. 乾かす前に「かわかすよ」と一声かける（予告なしで音を出さない）
4. 嫌がるそぶり（耳に手が上がる）が出たら一旦止めて距離を取る

## 注意事項

- 至近距離で急にスイッチを入れない（大泣き＋その場から動けなくなった記録あり: 日記 7/9）
- 泣いたときに「大丈夫だよ」と続けない。まず音を止める

「ドライヤーを我慢させる」のではなく「音と風を遠ざける」方が早く乾きます。音より風が嫌という仮説はまだ確かめきれていません。あなたの観察で更新してください。
