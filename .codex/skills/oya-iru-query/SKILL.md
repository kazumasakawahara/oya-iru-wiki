# oya-iru-wiki: query（照会）

このスキルは着火装置です。**手順の正典は Vault 直下の AGENTS.md** にあり、ここには複製しません。

1. Vault 直下の `AGENTS.md` を開き、**§2（絶対遵守のガードレール）と §3-2（query）**を読む
2. §3-2 に従い、purpose.md と index.md を読んでから関連ページを精読し、`[[wikilink]]` で出典を示して回答する
3. 共有・出力を伴う場合は **share_scope と `--allowlist` に従う（fail-closed）**。`origin-only` は決して含めない

このスキルと AGENTS.md が食い違って見えたら、**AGENTS.md が正しい**。手順の変更は AGENTS.md だけを編集すること。
