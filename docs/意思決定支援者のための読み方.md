# 意思決定支援者のための読み方

> この文書は、**この記録を受け取って読む人**——支援者・教員・相談支援専門員・後見人・いつか本人の隣に立つすべての人——のためのガイドです。親がこの記録を誰かに渡すとき、この1枚を一緒に渡してください。
>
> ここでいう意思決定支援者とは、**本人に関することは本人が決める、を支える人**のことです。本人の代わりに決める人ではありません。

## 1. まず知っておいてほしいこと — これは正解集ではありません

この記録は、親が日記として書き留めた日々の観察を、AI が整理して積み上げたものです。ここに書かれているのは**正解ではなく、その時点までの仮説**です。

- 「こうすれば伝わる」は「その時期・その場面ではそうだった」という記録です
- 手順書ときっかけは、本人の成長とともに古くなります
- **記録と目の前の本人が食い違ったら、正しいのは目の前の本人です**

この記録の価値は、あなたがゼロから手探りを始めなくて済むこと——**仮説の出発点**が手に入ることにあります。終着点ではありません。

## 2. 読む順番

初めてこの記録に触れるときは、この順で読んでください。

| 順 | 何を | なぜ |
|----|------|------|
| 1 | **こえ**（`wiki/koe/`・意思表出プロファイル） | バイブルの心臓。「はい・いいえ・嫌」をどう表すか、**誤読されやすいサイン**は何か。ここを読まずに本人と向き合わないでください |
| 2 | **直近の せんたく**（`wiki/sentaku/`・選択の記録）数件 | 最近の本人が、何を、どう選んでいるか。提示のしかたの実例 |
| 3 | **きっかけ**（`wiki/triggers/`）と**手順書**（`wiki/protocols/`） | 好き・苦手の条件と、機能している関わり方 |
| 4 | **ふしめ**（`wiki/fushime/`） | 就学・卒業などの節目で、何が比べられ、何が優先され、本人がどう関わったか——**判断の過程の記録** |
| 5 | **ひと**（`wiki/persons/`）と**ためしたこと**（`wiki/trials/`） | 全体像と、試行錯誤の歴史（失敗の記録を含む） |

急ぐ場合は、親に**意思決定支援ブリーフ**（こえ＋直近のせんたく＋関連する手順書を1枚に編んだもの）を頼んでください。

## 3. 事実と受けとめを区別して読む

この記録の第一の規律は、**本人の事実と、まわりの受けとめ（解釈）を分けて書く**ことです（purpose.md A-10）。

- せんたく のページには `## 本人のようす（事実）` と `## まわりの受けとめ` の2つの見出しが必ずあります。**根拠として使えるのは事実の欄**です。受けとめの欄は「親・支援者はそう解釈した」という記録であり、本人の意思そのものではありません
- 読み手のあなたも同じ規律で読んでください。「ゼリーを注視して手を伸ばした」は事実、「ゼリーが好き」は解釈です。解釈は仮説として持ち、**本人に確かめる方法を探す**のがこの記録の使い方です
- 親の思い（日記の「おもったこと」）は原則この記録の外（親の手元）に留まっています。もし共有されていたら、それは親が判断して開いたものです。**本人の事実としてではなく、親がどう受けとめてきたかの記録として**読んでください

## 4. 鮮度を必ず見る — 最新の本人に確認する

子どもは大人よりずっと速く変わります。各ページの頭にある次の項目を必ず見てください。

| 項目 | 意味 |
|------|------|
| `last_confirmed` | 「この内容がまだ正しい」と最後に確かめた日。**古いほど、目の前の本人とずれている可能性が高い** |
| `status: stale` | すでに現状と合わないと分かった過去の仮説。`superseded_by` が置き換え先を指します |
| `sentaku_date` / `occurred_on` | 出来事の日付。その時点の記録として読む（古くても価値は落ちません） |

こえ・手順書の確認目安は90日です。90日を超えた記述は「当時はそうだった」として扱い、**必ず最新の本人に確認してから**支援の前提にしてください。

## 5. 「通らなかった」の読み方

せんたく には `outcome: 通らなかった`——本人の選択が実現しなかった記録——が含まれ、必ず**そのときの理由**（override_reason）が書かれています。

- これは親や支援者を責める材料ではありません。安全・現実の制約の中での、その時点の判断の記録です
- **あなたへの問いは一つです: 「その理由は、今も有効か」。** 当時は乗換が困難だった、当時は体力がなかった——今はどうでしょうか。**通らなかった選択こそ、意思決定支援者が再検討すべき素材**としてここに残されています
- outcome の分布にも目を配ってください。「尊重された」ばかりなら、そもそも選択肢が狭く提示されていた可能性があります。「通らなかった」が続いていたら、大人の側の判断の癖が検証対象です

## 6. 失敗の記録を軽んじない

ためしたこと には失敗の記録が意図的に残されています。「言葉だけの二択では選べなかった」は、「実物を見せれば選べる」と同じだけの情報量を持ちます。**うまくいかなかった方法のリストは、あなたが同じ回り道をしないための地図です。**

## 7. してはならないこと

この記録の設計上の約束です。読み手にも守ってほしいことです。

1. **記録を根拠に本人の意思決定を先回りしない。** 「記録にこう書いてあるから、聞かなくても分かる」は、この記録の目的の正反対です。記録は**聞き方を知る**ために使ってください
2. **本人の自己決定権を、他者の決定権を侵す根拠にしない**（purpose.md A-6）。この記録には、本人が他者の決定権を学んできた過程（順番を待つ・貸してと言う）も含まれています。両方を尊重してください
3. **本人を「リスクのあるケース」として分類する読み方をしない**（purpose.md A-9）。行動の記録は、条件と対応の記録であって、人物の類型化のためのものではありません
4. **記録を本人の同意の代わりにしない。** share_scope（共有範囲の印）が守られた範囲であなたに届いた記録でも、そこから先の共有には本人・家族への確認が要ります
5. **本人の前で読み上げられない言葉で、この記録に追記しない。** この記録全体が「成人した20年後の本人が読む」前提で書かれています。あなたが書き足す場合も同じ基準です

## 8. この記録の続きは、あなたが目にする本人です

親がこの記録に残したのは、過去の観察です。**最新の1ページは、いつも目の前の本人が持っています。** 記録を読んだうえで、本人に聞いてください——この記録は、その聞き方を教えるために書かれました。

そして、あなたが本人と過ごす中で見つけたこと（この示し方で伝わった・このサインは違う意味だった）は、ぜひ親に返してください。それがこの記録の次の1行になります。
