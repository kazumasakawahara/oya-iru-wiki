# 年齢イベント表 — 本人の時間を見張る台帳

- 作成: 2026-08-13 ／ **制度の記述はすべて作成時点の一般的な概要**です（下の「この表の限界」を必ず読んでください）
- `docs/watchlist.md` が「外の変化（制度改正）」を見張るのに対し、この表は「**本人の時間**（何歳の何月に何が来るか）」を見張ります
- **機械（AI）は通知まで。申請する・しないの判断は親**です

## 1. 使い方

1. **導入時に1回だけ**、§2 の登録欄に子の生年月を書きます（導入手順.md Step 4。AI に「生まれは◯年◯月」と話せば AI が記入します）
2. AI は定期 ingest の締めに、この表から**次の12ヶ月に窓が開くイベント**を一言添えます（AGENTS.md §3-1 Step 3）
3. イベントが実際に起きたら（就学した・手帳を更新した等）、AI が **ふしめ（節目の記録）** への記録を提案します。判断の過程ごと残すのがこの Vault の流儀です

## 3. 年齢×制度イベント台帳（一般表）

「時期」は目安です。自治体・在籍先によって前後します。

| 時期 | 何が起きる・何ができる | 準備の窓（先回りの目安） |
|------|------------------------|--------------------------|
| 気づいたとき〜 | **療育手帳**の申請（知的障害。判定・名称・区分は自治体運用）。**特別児童扶養手当**（中度以上・20歳未満・在宅、所得制限あり）、重度なら**障害児福祉手当**も | 手帳は診断がなくても相談可。手当は手帳とは別に申請が必要 |
| 未就学期 | **児童発達支援**（児発）の利用。通所受給者証の申請 | 見学・相談はいつでも。受給者証は毎年更新 |
| 年中の冬〜年長の春 | **就学相談**の開始（特別支援学校／特別支援学級／通級等の検討） | **年長になる前の春が起点**。見学・体験は年長の夏まで、就学先の合意形成は年長の秋〜冬 |
| 年長の秋 | 就学時健康診断 | — |
| 6歳（小学校入学） | 就学。**放課後等デイサービス**（放デイ）に切替 | 放デイの見学・受給者証の変更は入学前の冬から |
| 小学6年 | 中学校（中学部）への進路検討 | 見学は小5〜小6の夏 |
| 中学3年 | 高等部・高校への進路検討 | 特別支援学校高等部の見学・体験は中2〜中3の夏 |
| 高等部1〜3年 | 現場実習・進路の絞り込み（就労移行・就労継続 A/B・生活介護・進学 等） | 卒業後の行き先の見学は**高2から**始めると選択肢が広い |
| **18歳** | **成年年齢**（契約・携帯・クレジット等が本人名義で可能に）→ **成年後見・保佐・補助／日常生活自立支援事業**の検討時期。**児童のサービス（放デイ等）は原則終了**し、障害者総合支援法の「者」のサービスへ切替 | 後見等は「必要になってから」で遅くないかの検討を17歳ごろから。者へのサービス切替は在学中から相談支援と併走 |
| 高等部卒業（18歳の年度末） | 卒業＝日中の居場所の切替。**ふしめ**として必ず記録したい節目 | — |
| **19歳** | **障害基礎年金（20歳前傷病）の請求準備を始める年** | 診断書・初診日の記録・本人の日常の様子の整理に時間がかかる。**20歳の誕生日を待たずに19歳のうちに着手**。請求書類は誕生日前3ヶ月から提出可 |
| **20歳** | **障害基礎年金**の請求（20歳前傷病は20歳から）。**特別児童扶養手当・障害児福祉手当は終了**（成人向けの特別障害者手当は別要件）。国民年金の手続き（障害基礎年金受給なら法定免除） | 年金の「日常の様子」の申立てには、**この Vault の日記と せんたく の蓄積がそのまま素材になります** |

### 年齢によらず毎年・数年おきに来るもの

| 周期 | 何が来るか |
|------|-----------|
| 毎年 | 通所受給者証（児発・放デイ等）の更新。手当の現況届・所得状況届 |
| 数年おき（自治体・判定による） | **療育手帳の再判定**（次回判定年月は手帳に記載。この表の §2 カレンダーに転記しておく） |
| 転居・進級・家族の変化のたび | サービス支給量・利用計画の見直し。**ふしめ** への記録を検討 |

## 4. この表の限界（必ず読んでください)

- **この表は一般的な制度の見取り図であり、個別の助言ではありません。** 手当の所得制限、手帳の判定基準、18歳以降の特例（高校在学中の放デイ等）、年金の認定は、**自治体・在籍先・個々の状況で異なります**。実際の申請は必ず市区町村の障害福祉窓口・年金事務所・在籍校に確認してください
- **制度は改正されます。** この表の内容は作成時点（2026-08-13）の概要です。一次情報源の監視は `docs/watchlist.md` が担っており、改正が検知されたらこの表も見直します（確認待ちに起票されます）
- 迷ったら AI に「◯◯について、watchlist の一次情報源で最新を確かめて」と頼んでください
