# くわしい手順書 ③　Claude を用意して、フォルダを見せる

> **この手順書は、AI を日常的に使ったことがない方のためのものです。** この仕組みの相棒になる AI（ここでは Claude を例にします）を契約し、パソコンに入れ、記録のフォルダを見せられるようにします。ここが導入の**やま場**です——ここを越えれば、あとは話すだけです。
>
> 所要時間: 20〜30分 ／ 前の手順: [② Obsidian を入れて、Vault として開く](02_Obsidianを入れてVaultとして開く.md) ／ 次の手順: [④ 黒い画面をこわがらない](04_黒い画面をこわがらない.md)
>
> この仕組みは特定の AI 製品に固定されていません（指示書 AGENTS.md はどの AI でも読める書き方です）。ただし**動作を確認済みなのは Claude** なので、この手順書は Claude の画面で説明します。別の AI を使う場合も「有料プランで、学習に使われない設定で、フォルダを見せる」という骨組みは同じです。

## 0. いちばん大事な確認 — 学習に使われないこと

日記には、お子さんの発達・健康・行動という、**最も繊細な個人情報**が含まれます。だから AI 選びで確かめることは一つだけです。

**「私が入力した内容は、AI の学習（モデルの改善）に使われますか？」**

- **無料プランは使わないでください。** 入力内容がサービスの改善に使われうるものが多いためです
- 有料プランでも、**設定画面のプライバシー項目**で、入力内容を学習に使う設定がオフになっていることを確認してください
- 確かめ方が分からなければ、契約前にその AI 自身に上の質問をそのまま聞いてください。**曖昧な答えしか返らない AI は、この用途に使わない**でください

## 1. Claude の有料プランを契約する

1. ブラウザで `https://claude.com` を開きます
2. アカウントを作ります（メールアドレスで登録できます）
3. 有料プラン（個人向けの月額プラン）にアップグレードします。クレジットカードが必要です
4. 契約後、設定（Settings）のプライバシー項目を開き、**会話をモデル改善に使う設定がオフ**になっていることを確かめます。見つからなければ、Claude に「私の入力が学習に使われない設定になっているか、確認のしかたを教えて」と聞いてください

## 2. Claude Desktop（パソコン用アプリ）を入れる

ブラウザ版の Claude はパソコンのフォルダを見られません。**パソコン用アプリが必要**です。

1. `https://claude.com/download` から、お使いの OS 用の Claude Desktop をダウンロードします
2. インストールします（Mac は dmg を開いてアイコンを Applications へドラッグ、Windows は exe を実行。②の Obsidian と同じ要領です）
3. 起動して、1で作ったアカウントでサインインします

## 3. 受付箱を作る

AI に見せるフォルダは2つです。そのうち1つ「受付箱」をここで作ります。

1. **デスクトップに新しいフォルダを1つ**作り、名前をこのページからコピーして `📮受付箱` にします（📮 はデスクトップで一目で見つけるための目印です。絵文字の入力がむずかしければ `受付箱` だけでも大丈夫——AI はどちらも受付箱として扱います）
   - Mac: デスクトップの何もない所を右クリック → 「新規フォルダ」
   - Windows: デスクトップの何もない所を右クリック → 「新規作成」→「フォルダー」
2. これだけです。連絡帳の写真や園・学校のプリントは、今後ぜんぶここに入れます。中身は AI が読んで記録の棚に移し、受付箱は空に戻ります

> **日記はここを通りません。** 日記はチャットで話すだけ。受付箱は「書類の入口」です。
> **Vault の中に作らないでください。** 手前に一段あることで、置き間違いを記録される前に取り消せます。

## 4. Claude にフォルダを見せる（差込口の設定）

Claude Desktop とパソコンのフォルダをつなぐ仕組みを **MCP（差込口）**と呼びます。見せるフォルダは次の**2つ**です。

1. **記録の Vault**（例: `Obsidian/oya-iru-wiki`）
2. **受付箱**（例: デスクトップの `📮受付箱`）

### 方法1: 設定画面から（まずこちらを試す）

1. Claude Desktop の**設定**（歯車アイコン）を開きます
2. **「拡張機能」または「コネクタ」**という項目を探します（バージョンにより名前が違います）
3. その中の**「ファイルシステム」（Filesystem）**を有効にし、アクセスを許可するフォルダとして上の2つを追加します

### 方法2: Claude 自身に設定内容を作ってもらう（方法1で見つからないとき）

**先に大事な注意を一つ。** 設定ファイルは、**Claude が動いている間に書き換えると、消されてしまうことがあります**（Claude はチャットを開いた瞬間などに設定を書き戻すため）。だから方法2は、必ずこの順番で進めます——**①案内をもらう → ②メモに控える → ③Claude を完全終了する → ④編集する → ⑤起動する**。

1. Claude Desktop のチャットに、そのままこう貼り付けます。

   > 「あなた（Claude Desktop）に私のパソコンの2つのフォルダ——`Obsidian/oya-iru-wiki` とデスクトップの `📮受付箱`——を見せたい。filesystem の差込口（MCP）の設定方法を、私のパソコンの画面に沿ってひとつずつ案内してください。私はパソコンに詳しくありません。**あとで Claude を終了してから作業するので、手順の全文と、貼り付ける設定の内容を、コピーして残せる形でまとめて出してください。**」

2. 出てきた手順と設定内容を、**メモ帳（Windows）／メモ・テキストエディット（Mac）に貼り付けて保存**します（Claude を終了すると画面が見られなくなるため）
3. 次の「完全終了」を行ってから、控えた手順どおりに設定ファイルを編集します
4. 編集を保存したら、Claude Desktop を起動し直します

### 設定のあと、必ず「完全終了」する — ここが全行程でいちばんのつまずきポイント

**設定は、アプリを完全に終了して起動し直すまで反映されません。** そして「終了したつもり」がいちばん起きやすいのが Windows です。

**Mac の場合**

- ウィンドウを閉じる（赤い ●）だけでは終了していません。**`command` + `Q`** を押します（またはメニューバーの Claude → 終了）

**Windows の場合（3段階で確かめてください）**

1. ウィンドウの「×」で閉じます——**これだけでは終了していません**。Claude は画面右下のタスクトレイで動き続けます
2. 画面右下の時計の近くにある **「^」印（かくれているインジケーターを表示）をクリック**します。**Claude のアイコンはこの「^」の中に隠れていることがほとんど**で、パッと見では見えません。見つけたら**右クリック → 「終了（Quit）」**
3. **アイコンが見つからないとき・本当に終了したか不安なときの確実な方法**: キーボードで `Ctrl` + `Shift` + `Esc` を同時に押すと「タスクマネージャー」が開きます。一覧（プロセス）から **「Claude」を探して選び、「タスクの終了」**を押します。**「Claude」が複数行あることがありますが、ぜんぶ終了して大丈夫です**

そのうえで、もう一度 Claude Desktop を起動します。起動し直したら、次の「5. つながったかを確かめる」で反映を確認してください。

## 5. つながったかを確かめる

Claude にこう聞いてください。

> 「Vault のフォルダの中身を見て、raw の下にいくつ棚があるか教えてください」

**「8つ」**と返ってくれば成功です。おめでとうございます——やま場は越えました。

これでこの手順書は終わりです。[④ 黒い画面をこわがらない](04_黒い画面をこわがらない.md)（動作確認の検査）へ進んでください。

## よくあるつまずき

| 症状 | 対処 |
|------|------|
| フォルダを見てくれない | 9割は「完全終了していない」が原因です。Windows は「×で閉じた＝終了」ではありません。タスクマネージャー（`Ctrl`+`Shift`+`Esc`）で「Claude」を全部終了 → 再起動 |
| 設定ファイルを直したのに、開き直すと元に戻っている | Claude が動いている間に編集したためです（Claude が設定を書き戻します）。**完全終了 → 編集 → 起動**の順でやり直してください |
| どのフォルダを指定したか分からなくなった | Claude に「いま見えているフォルダを教えて」と聞く |
| 「8つ」と違う答えが返る | Vault のフォルダではなく別のフォルダを指定しています。①で置いた場所（例: `Obsidian/oya-iru-wiki`）を指定し直してください |
| 受付箱を Vault の中に作ってしまった | デスクトップに作り直して、指定もし直してください |
| 設定画面に「拡張機能」も「コネクタ」も見当たらない | 方法2（Claude 自身に案内させる）へ。アプリの更新（メニューから最新版を確認）も試してください |
| 家族のパソコンでも使いたい | 同じ設定を各パソコンで行えば使えますが、Vault のフォルダを共有する方法（家庭内の共有方法・クラウド同期の可否）は、記録がどこに置かれるかに関わります。AI に相談してから決めてください |
