# くわしい手順書 ①　テンプレートを手に入れる（GitHub から）

> **この手順書は、GitHub というサイトを初めて使う方のためのものです。** アカウント登録は不要で、かかるお金もありません。やることは「サイトから ZIP ファイルを1つダウンロードして、決めた場所に置く」だけです。
>
> 所要時間: 5〜10分 ／ 前の手順: なし（ここが最初です） ／ 次の手順: [② Obsidian を入れて、Vault として開く](02_Obsidianを入れてVaultとして開く.md)

## GitHub とは何ですか？

プログラムや文書のひな型を置いておける、世界で広く使われている公開棚のようなサイトです。このテンプレートも GitHub に置いてあり、**誰でも・無料で・登録なしに**持ち帰れます。「ダウンロードしたら課金される」「登録を求められる」ことはありません。

## 方法A: ZIP でダウンロードする（おすすめ・登録不要）

### 1. テンプレートのページを開く

ブラウザ（Safari・Chrome・Edge など）で、次のアドレスを開きます。

```
https://github.com/kazumasakawahara/oya-iru-wiki
```

英語まじりの画面が出ますが、読む必要はありません。ファイルの一覧が並んでいれば正しいページです。

### 2. 緑色のボタンから ZIP を選ぶ

1. ページの右上あたりにある**緑色の「Code」ボタン**を押します
2. 開いたメニューのいちばん下にある **「Download ZIP」** を押します
3. ダウンロードが始まります（数MB。すぐ終わります）

> 見た目が変わっていて緑のボタンが見つからないときは、そのページの URL を AI に伝えて「このページから ZIP をダウンロードする場所を教えて」と聞いてください。

### 3. ZIP を展開する

- **Mac**: ダウンロードフォルダの `oya-iru-wiki-main.zip` を**ダブルクリック**すると、`oya-iru-wiki-main` というフォルダができます
- **Windows**: `oya-iru-wiki-main.zip` を**右クリック → 「すべて展開」**を選びます

> **ここでつまずく方が多いポイント**: Windows では、ZIP をダブルクリックすると「中をのぞいている」だけの状態になります。見た目はフォルダですが、まだ展開されていません。必ず**右クリック → すべて展開**をしてください。

### 4. 置き場所に移す

展開してできたフォルダを、ホームフォルダの下の `Obsidian` フォルダに移します（`Obsidian` フォルダがなければ作ってください）。

- Mac の例: `/Users/あなたの名前/Obsidian/oya-iru-wiki`
- Windows の例: `C:\Users\あなたの名前\Obsidian\oya-iru-wiki`

移すときに、フォルダ名の末尾の `-main` は消して `oya-iru-wiki` にしておくと、この後の説明とそろって迷いません。

> **なぜ「書類」や「デスクトップ」ではだめなのか。** だめではありません。ただ、クラウド同期（iCloud・OneDrive）が自動で効くフォルダに置くと、お子さんの記録がクラウドに上がります。それを承知で選ぶのでない限り、**同期対象でない場所**（ホーム直下の `Obsidian` フォルダなど）をおすすめします。

### 5. できたかどうかの確かめ

フォルダを開いて、中に `README.md` `purpose.md` `記入例` などが見えれば成功です。これでこの手順書は終わりです。[② Obsidian を入れて、Vault として開く](02_Obsidianを入れてVaultとして開く.md) へ進んでください。

> ZIP で入れた場合、あとで一度だけ「実行の許可」を戻す作業があります（[④ 黒い画面をこわがらない](04_黒い画面をこわがらない.md) で説明します）。今は気にしなくて大丈夫です。

## 方法B: Git でクローンする（Git を使ったことがある方向け）

Git が入っているパソコンなら、ターミナルで次を実行します。

```bash
git clone https://github.com/kazumasakawahara/oya-iru-wiki.git ~/Obsidian/oya-iru-wiki
```

- クローンなら、後で「実行の許可」を戻す作業は不要です
- **実データの運用を始める前に、公開への道を断つ**（`git remote remove origin`）ことを忘れないでください（導入手順.md Step 1）
- 「Git って何？」という方は、方法A で何も問題ありません。Git は履歴を残したい人向けの追加の道具です

## よくあるつまずき

| 症状 | 対処 |
|------|------|
| ダウンロードした ZIP が見つからない | ブラウザの「ダウンロード」フォルダを見る（Mac: Dock の右端／Windows: エクスプローラーの「ダウンロード」） |
| 「このファイルは安全でない可能性があります」と出た | GitHub からの ZIP は一般的な配布方法です。「保存」「継続」を選んで大丈夫です。不安なら URL が `github.com/kazumasakawahara/oya-iru-wiki` であることを確かめてください |
| フォルダの中に同じ名前のフォルダがもう一段ある | 展開のしかたによって起きます。内側の（`README.md` が直接見える方の）フォルダを置き場所に移してください |
| 英語の画面がこわい | 読まなくて大丈夫です。押すのは緑の「Code」→「Download ZIP」の2つだけです |
